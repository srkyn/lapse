# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Report security issues privately by opening a [GitHub Security Advisory](https://github.com/srkyn/lapse/security/advisories/new).

Do not open a public issue for security vulnerabilities.

Include a description of the issue, steps to reproduce, and any relevant environment details. I'll respond within a few days and work toward a fix for confirmed vulnerabilities.
